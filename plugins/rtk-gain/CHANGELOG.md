# Changelog

All notable changes to `rtk-gain` are recorded here, newest first.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/). Each version is released as the tag `rtk-gain-v<version>`.

## [0.1.0] - 2026-10-07

### Added
- Status line with the tokens [RTK](https://www.rtk-ai.app) has saved, refreshed at session start and after each Bash command.
- `/rtk-gain` draws the `rtk gain` report as a card: total saved with a gauge, totals, and a per-command table with bars and colored rates.
- English and French UI, with a `language` option (`auto`, `en` or `fr`).
