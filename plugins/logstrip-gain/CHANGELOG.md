# Changelog

All notable changes to `logstrip-gain` are recorded here, newest first.
Versions follow [Semantic Versioning](https://semver.org/), released as `logstrip-gain-v<version>`.

## [0.1.0] - 2026-10-09

### Added
- Read-only status line with cumulative estimated LogStrip token savings.
- `/logstrip-gain` card with savings gauge, totals and recent runs.
- English and French UI, with configurable language.
- Statistics via `logstrip --telemetry`, without compression or output interception.
